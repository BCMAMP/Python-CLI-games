An interactive Command Line Interface (CLI) word scramble game application built using Python in Visual Studio Code.

Features & Technical Implementation:
- OOP & Data Structures: Utilization of a core class to encapsulate game logic, alongside dynamic processing of dictionaries and lists.
- String & Randomization Algorithms: Implementation of `random.sample()` to shuffle word characters without altering the original data.
- Game State Management: Score tracking (correct/incorrect), verification of word availability within categories, and input validation using `try-except` blocks.

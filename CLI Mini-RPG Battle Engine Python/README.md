A command-line interface (CLI) based turn-based combat system simulation built using Python in Visual Studio Code.

Key Technical Features:
- Object-Oriented Programming (OOP): Implementation of inheritance (Character – Hero/Enemy) and encapsulation.
- Game Logic & Turn System: Character state management, damage calculation, and a dynamic buff/debuff system.
- Error Handling & Input Validation: Implementation of try-except blocks to prevent errors caused by invalid user input.
